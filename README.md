# Swarm Defense

A Godot 4 game project. The roadmap describes it as a cooperative multiplayer sci-fi survival and base-building game: expand a mining and comms network, manage light-speed delays, and defend bases from the Swarm.

## Run

Open `swarm-defense/project.godot` in Godot 4.7 and run the project. The main scene is `scenes/core/main_menu.tscn`.

## Layout

| Path | What it is |
|---|---|
| `swarm-defense/` | The Godot project |
| `swarm-defense/scenes/` | Scenes: core, celestial, buildings, ships, ui, tools |
| `swarm-defense/scripts/` | GDScript: autoload singletons in `globals/`, game systems in `systems/`, plus ui, ships, shaders, tools, utils |
| `swarm-defense/assets/quaternius/` | Third-party 3D assets |
| `swarm-defense/tests/` | Test script |
| `ROADMAP.md`, `ROADMAP.html` | Development roadmap and planned design |
| `opencode.json` | opencode config that enables a Godot MCP server |
